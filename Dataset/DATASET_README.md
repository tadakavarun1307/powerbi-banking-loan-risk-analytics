# Banking Loan & Credit Risk Analytics Dataset

Synthetic portfolio dataset created for a Power BI/SQL analytics portfolio project.

## Tables
- customers.csv — 5,000 customer records
- loans.csv — 8,000 loan applications/loans
- payments.csv — 24,000 payment transactions
- branches.csv — 30 branch records

## Intended analysis
- Loan approval and rejection trends
- Loan portfolio composition
- Credit-risk segmentation
- Default-rate analysis
- Branch performance
- Payment timeliness
- Customer and loan trends over time

This is synthetic data and does not contain real customer information.
